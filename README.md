# Trend Analiz Uygulaması

Bu uygulama, Google Trends verilerini çeker ve Gemini kullanarak analiz eder.

## Kurulum
1. `pip install -r requirements.txt`
2. `.env` dosyası oluşturun (`.env.example`'dan kopyalayarak) ve API anahtarınızı ekleyin.
3. Uygulamayı çalıştırın: `uvicorn app.main:app --reload`
